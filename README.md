# Outreach for Claude Code

Researches companies and drafts cold email sequences from your real experience, then puts them
on the Outreach website for you to approve. Nothing is sent until you approve it.

You need an Outreach account (by invite) and a paid Claude plan.

## Install

1. On the Outreach website, open the **Claude Code** page and click **Create token**.
2. In Claude Code, run:

   ```
   /plugin install outreach --marketplace qgatssdev/outreach-plugin
   ```

   Paste your token when it asks.
3. Say **"get started"**.
